# Colegio Internacional Los Senderos

Sitio web institucional del colegio. HTML + CSS puro, sin frameworks.

## Páginas

- **index.html** — Inicio, área académica, estudiantes, apoderados
- **registro.html** — Formulario de inscripción de alumnos
- **talleres.html** — Talleres extraprogramáticos
- **galeria.html** — Galería de imágenes

## Abrir

Abrir `index.html` en cualquier navegador.
